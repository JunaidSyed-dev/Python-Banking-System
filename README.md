# 🏦 Banking System Simulation using Python OOP

## 📖 Project Overview

This project is a simple Banking System Simulation developed using Python and Object-Oriented Programming (OOP) principles. It demonstrates core OOP concepts such as Abstraction, Encapsulation, Inheritance, and Polymorphism while implementing basic banking operations.

## ✨ Features

### 💰 Savings Account

* Deposit money
* Withdraw money
* Minimum balance maintenance of ₹500
* Balance inquiry

### 🏢 Current Account

* Deposit money
* Withdraw money
* Overdraft withdrawal facility
* Balance inquiry

## 🧠 OOP Concepts Implemented

### 🔹 Abstraction

Implemented using Python's Abstract Base Class (ABC) and abstract methods.

### 🔹 Encapsulation

Account balances are stored as private attributes using double underscores (`__balance`).

### 🔹 Inheritance

`SavingsAccount` and `CurrentAccount` inherit from the `Account` abstract class.

### 🔹 Polymorphism

Each account type provides its own implementation of deposit and withdrawal methods.

## 🛠️ Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
